# Security

## Authorised use only

kryptonite tells an AI agent to attack software. Only run it against apps you own or have written permission to test, in a local or test environment. Never point it at systems you do not control. You are responsible for how you use it.

## Reporting a problem in kryptonite

If kryptonite itself can be made to do something unsafe — for example, write to a working tree without approval, reach production infrastructure, or leak secrets into its reports — please report it privately through [GitHub security advisories](https://github.com/levitasOrg/kryptonite/security/advisories/new) instead of opening a public issue.
