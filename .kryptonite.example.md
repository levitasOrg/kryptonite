# .kryptonite.md — per-target config (optional)

Copy this file into the root of the app you're running kryptonite against
and rename it to `.kryptonite.md`. kryptonite's Phase 1 (`phases/1-recon-and-baseline/SKILL.md`)
reads `.kryptonite.md` first, when present, and prefers its answers over
auto-detection wherever the two conflict. Every field below is optional —
omit or leave blank any field you don't need; kryptonite falls back to
auto-detection (`scripts/detect_stack.py`) and its own judgment for anything
not pinned here. Delete the comment lines or leave them — only the fields
under each heading are read.
